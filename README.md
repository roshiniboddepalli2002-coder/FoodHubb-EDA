# FoodHub – Exploratory Data Analysis

## Project Overview
This project analyses food delivery data to understand customer ordering behaviour, restaurant performance and delivery trends.

## Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data inspection and cleaning
- Univariate analysis
- Bivariate analysis
- Order analysis
- Restaurant rating analysis
- Food preparation and delivery time analysis
- Business insights and recommendations

## Objective
To identify patterns in customer orders, restaurant performance and delivery operations through exploratory data analysis.
